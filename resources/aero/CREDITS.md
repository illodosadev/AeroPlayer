# Aero visual assets: provenance

Every file under `resources/aero/backgrounds`, `resources/aero/icons` and `resources/aero/fonts` has one row here. A test (`tests/Feature/AeroAssetsTest.php`) fails when a file has no row.

| File | Origin | Added |
|------|--------|-------|
| `backgrounds/sky.svg` | Hand-made for this project (sky, sun, clouds, hill, water). | 2026-11-10 |
| `fonts/selawik-regular.woff2` | Selawik 1.01, Regular, from <https://github.com/microsoft/Selawik/releases/download/1.01/Selawik_Release.zip>. SIL Open Font License 1.1. | 2026-11-10 |
| `fonts/selawik-bold.woff2` | Selawik 1.01, Bold, from <https://github.com/microsoft/Selawik/releases/download/1.01/Selawik_Release.zip>. SIL Open Font License 1.1. | 2026-11-10 |
| `public/fonts/aero-display.woff2` (outside this folder, not versioned) | Font for all text: the owner's own copy of FOT-NewRodin Pro EB, reduced to the Latin characters. Copied to the server separately. | 2026-11-11 |
| `fonts/OFL-selawik.txt` | Licence text of Selawik, from <https://raw.githubusercontent.com/microsoft/Selawik/master/LICENSE.txt>. | 2026-11-10 |
